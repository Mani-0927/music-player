## Project Overview
This project is a web-based Music Player application developed using HTML, CSS, and JavaScript.  
The application allows users to play audio files, manage a playlist, control volume, and track song progress through a clean and responsive user interface.

## Project Description
The Music Player provides essential music playback features such as play, pause, next, previous, seek, and volume control.  
It supports locally stored audio files and focuses on delivering a smooth and user-friendly experience across all devices.

## Features
- Clean and intuitive user interface  
- Play, Pause, Next, and Previous controls  
- Progress bar with seek functionality  
- Volume control slider  
- Playlist with active song highlighting  
- Displays current time and total duration  
- Responsive design for all screen sizes

## How to Use
1. Download and extract the project folder.
2. Add MP3 audio files inside the `songs` folder.
3. Open `index.html` in any modern web browser.
4. Select a song from the playlist.
5. Use the controls to play, pause, seek, or adjust volume.
